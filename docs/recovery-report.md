# Отчёт о восстановлении LinuxLab

Дата: 30 октября 2026 года.

## Фактический вход

`LinuxLab.html`: 588 541 байт; SHA-256 `0422e28285fa99c62afc223e76d0bf64254e1be5ccc912ce8df2dbd461a29ba5`.

Это не указанная в задании последняя сборка с SHA-256 `405ba0cf41c0586760d30b147744e9957a45a5eeeed88106359a7f344a302b3b`. Точная дата и номер входной версии не объявлены. Версия установлена по составу кода: 12 разделов, 41 теоретический блок, 26 лабораторных, но без отдельного учебного маршрута и 13 дополнений.

Вход сохранён побайтово в `backups/LinuxLab.original.html`, локально установлен режим 0444. Извлечены все исполняемые script/style в исходном порядке: course, engine, semantics, visuals, reader, app; style, redesign, semantics. Неисполняемый script содержит OFL; шрифт извлечён из data URI. Список блоков — `input-manifest.json`. Внешних загрузок для работы входного курса нет.

Удалённый origin проверен штатным HTTPS Git-прокси. На старте восстановления `git ls-remote origin` успешно завершался без refs; `refs/heads/main` отсутствовала. Локальный checkout был без коммитов и файлов проекта. Это наблюдение текущей среды, не вывод о сохранности диска старой задачи.

Двенадцатый раздел установлен из COURSE: `incident`.

Исторические неизвестные ID уроков не выдумываются как точные оригиналы. Сохранены три известных ID (`foundation-system`, `foundation-terminal`, `foundation-paths`) и все 26 ID лабораторий входной версии. Остальные базовые ID созданы при восстановлении. Неизвестные ключи учебного прогресса сохраняются при импорте, но не означают автоматического прохождения новых уроков. Формат утраченного финального экспорта полностью неизвестен; проверена совместимость с исходным v1 и новым форматом этой сборки.

Это функциональное восстановление, не побайтовое восстановление неизвестных curriculum.js, learning.js, text-tools.js, build.py или прежних тестов. Исторические числа прошедших тестов из задания не используются как результаты текущего запуска.

Промоссылки не включались; команды из стороннего README не запускались. Ссылки на источник и профильную документацию доступны в разделе «Источники».

## Выполненные проверки

- `node tests/engine.test.cjs`: 10 тестов пройдены. Они включают все старые terminal-решения, все шаги 12 коротких тренировок и 12 тренировок разделов, положительные и отрицательные проверки новых заданий, snapshot/restore, grep/diff status, lookup, ограничение исполняемого синтаксиса.
- `python3 tests/text_tools_test.py`: один тест с 10 отдельными конвейерами; результаты совпали с реальными GNU-утилитами при LC_ALL=C на контролируемом файле.
- `python3 tests/browser_test.py`: 8 сценариев пройдены; отдельный прямой `file://` сценарий пропущен из-за `ERR_BLOCKED_BY_ADMINISTRATOR` в политике управляемого Chromium. Он не засчитывается как пройденный. Та же автономная сборка проверена через локальную подстановку HTTPS-ответа без внешних запросов.
- Браузерный путь с нуля прошёл все 54 урока, все 12 коротких тренировок и все 12 тренировок разделов через ввод команд и выбор ответов. Компонентные сценарии отдельно используют явно подготовленный профиль.
- Проверены блокировки неподготовленных задач/экзамена, отдельное исполнение подставленной команды, результаты файлов новых задач, независимость модели ссылок, reload, экспорт/импорт, прежний v1, экранирование заметок, отказ localStorage, отключённые подсказки экзамена, уникальная очередь и истечение времени.
- Проверены восемь представлений на 1440, 768, 390 и 360 px при тексте 20 px: горизонтального переполнения страницы нет. Во всех сценариях нет необработанных JS-ошибок и внешних запросов.
- `python3 tests/package_test.py`: 3 проверки пройдены: отпечаток backup, автономность ресурсов, совпадение HTML в VPS-архиве, права публичного файла, checksums и содержимое архива исходников.
- Комплект Compose реально запущен в локальном Docker. Первый запрос обнаружил HTTP 403 из-за режима 0600, унаследованного от umask среды. Сборщик исправлен: публичный index.html получает 0644 и каталог — 0755. Повторный запрос дал HTTP 200; ответ побайтово совпал с финальной автономной сборкой (794 489 байт, SHA-256 `60f1845bab60d1686b96318508a306c6b31b236ade9deb1eaf6d17e970a9a9b8`). Тестовый контейнер и его сеть удалены штатным compose down.

## Выдача и ограничения

`dist/LinuxLab.html` и `dist/LinuxLab-course.html` одинаковы. `dist/LinuxLab-project.zip` содержит исходники, backup, тесты и документацию. `dist/LinuxLab-VPS.zip` содержит проверенный index.html, compose.yaml и инструкцию. SHA-256 выдачи записаны в `dist/checksums.json`.

Приложение не исполняет произвольный Bash, AWK, TLS, rsync, RAID или namespaces. Реальный VPS пользователя не разворачивался. Новый origin требует переноса прогресса JSON; сам HTML не содержит localStorage пользователя. Опубликование снимка облачной среды и успешное восстановление в новой задаче не подтверждены текущими локальными проверками.
