# LinuxLab — Linux для DevOps

Автономный интерактивный курс на русском: 54 урока, 12 разделов, 12 коротких тренировок, 12 тренировок разделов и 28 самостоятельных заданий. Без аккаунта, внешних API и серверной базы данных. Терминал — ограниченный JavaScript-симулятор, не Bash компьютера пользователя.

## Использование и скачивание

Скачайте `dist/LinuxLab.html` через кнопку **Download raw file** в GitHub и откройте в современном браузере. Изображения, шрифт Onest и код встроены; Интернет для курса не нужен. В отдельных управляемых браузерах `file://` может запрещаться политикой — используйте статический веб-сервер.

- `dist/LinuxLab-project.zip` — исходники, исходный HTML, тесты и документация.
- `dist/LinuxLab-VPS.zip` — `index.html`, Docker Compose и инструкция VPS.
- `dist/checksums.json` — размеры и SHA-256 файлов выдачи.

Обучение: объяснение → пример → тренировка → вопрос → подготовка к задаче → самостоятельное решение и разбор. Начальный маршрут: `#learn/foundation-system`. Доступ к задачам и экзамену требует подготовки. В «Атласе связей» есть 12 независимых моделей, а в уроке ссылок — дополнительная модель inode и дескриптора.

## Прогресс и перенос

Прогресс сохраняется в `localStorage` под прежним ключом `linuxlab.v1`, вид — `linuxlab.reader.v1`. В «Журнале инженера» доступны экспорт и импорт JSON. Экспорт включает уроки, вопросы, тренировки, результаты задач, заметки, повторение, историю экзаменов и настройки чтения. Импорт восстанавливает результаты, но сбрасывает временные стенды и активный экзамен. Старый формат версии 1 без новых полей принимается.

HTML не содержит персональные данные из localStorage. Для перехода с файла на VPS или другой origin сначала экспортируйте JSON, затем импортируйте его на новом адресе. Между устройствами автоматической синхронизации нет. Если хранение запрещено браузером, курс показывает предупреждение и оставляет экспорт доступным.

## Разработка

Нужны Python 3.10+ и Node.js 18+ для проверок. Сборка не требует Python/npm-зависимостей:

```sh
python3 build.py
node tests/engine.test.cjs
python3 tests/text_tools_test.py
```

Для браузерных проверок нужны Chromium и Python Playwright:

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements-test.txt
.venv/bin/python tests/browser_test.py
```

Тест использует `/usr/bin/chromium`; замените путь в тесте, если браузер установлен иначе. В текущей облачной среде Python Playwright, Node и Chromium уже доступны. Браузерные проверки требуют разрешения среды на создание процессов и сокетов. В управляемом Chromium `file://` заблокирован; этот единственный тест отмечается skipped, остальные работают с локальной подстановкой сборки на тестовом HTTPS-origin без внешних запросов.

Для разработки запустите `python3 -m http.server 8080 --bind 127.0.0.1` из корня проекта; исходники доступны по пути `/src/`, автономная сборка — `/dist/LinuxLab.html`. Это локальный сервер разработчика.

Скрипты используют общий браузерный контекст; порядок задан в `src/index.html`. Не переводите файлы в ES modules без проверки зависимостей. Учебные команды никогда не выполняются реальной ОС. Поддерживаемые подмножества и ограничения есть в `help` и `src/text-tools.js`.

## Происхождение и достоверность

Исходный `backups/LinuxLab.original.html` сохранён побайтово. Из него извлечены шесть JS-блоков, три CSS-блока, шрифт и OFL. Исходная версия содержала 41 теоретический блок внутри 12 разделов и 26 задач, но не содержала пошагового маршрута 54 уроков.

Учебная организация, вопросы, дополнительные объяснения, текстовые инструменты, тесты и сборщик восстановлены заново по пользовательскому заданию. Это функциональное восстановление с сохранением прежних лабораторий, а не точная копия неизвестного финального исходного проекта. Неизвестные ID утраченных уроков нельзя достоверно сопоставить; импорт их сохраняет без автоматического зачёта новых уроков. Три известные ID и все существовавшие во входном HTML ID задач сохранены. Исходный PDF не приложен, сверка с ним не выполнена.

Подробности: `docs/recovery-report.md`, `docs/input-manifest.json`. Источник тем дополнений: [Linux-cheatsheet, закреплённая ревизия](https://github.com/faster-droid/Linux-cheatsheet/blob/e3869d923be9843715aaf74a9228f045906d351f/README.md); объяснения написаны самостоятельно. Шрифт Onest распространяется по SIL OFL, текст лицензии — `assets/fonts/OFL.txt` и внутри сборки.

Размещение: `deploy/README-VPS.md`. Реальный VPS пользователя не менялся.
